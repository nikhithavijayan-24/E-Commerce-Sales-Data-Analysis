# 🛒 E-Commerce Sales Data Analysis | Microsoft Excel

### 📊 Data Cleaning • Exploratory Data Analysis • Statistical Analysis • Interactive Dashboard

## 📌 Project Overview

This project focuses on analyzing an **E-commerce Sales Dataset** using Microsoft Excel to understand sales performance, customer behavior, product information, and store-level performance. The project involves data cleaning, data transformation, descriptive statistical analysis, and interactive dashboard development to generate meaningful business insights.

## 🎯 Project Objectives

- Clean and transform raw datasets to improve data quality and consistency.
- Perform descriptive statistical analysis to understand sales distribution and performance.
- Analyze sales trends across payment types, stores, and time periods.
- Develop an interactive dashboard to support data-driven decision-making.

## 📂 Dataset Information

The project uses a relational dataset consisting of four main components:

| Dataset            | Records | Description                       |
| ------------------ | ------- | --------------------------------- |
| Customer Dimension | 500     | Customer details and demographics |
| Product Dimension  | 100     | Product details and categories    |
| Store Dimension    | 20      | Store information and regions     |
| Sales Fact         | 2,000   | Transaction and sales information |

## 🛠️ Tools & Technologies

- **Microsoft Excel**
- Excel Tables
- PivotTables & Pivot Charts
- Interactive Slicers
- Descriptive Statistics

## 🔄 Project Workflow

**1. Data Cleaning & Transformation**

- Removed duplicate records.
- Identified and treated missing values using Mean, Median, and Mode where applicable.
- Standardized text formatting.
- Removed the Sub_Category column from the Product Dimension table as instructed.
- Converted cleaned datasets into Excel Tables.

**2. Excel Functions & Analysis**

Applied various Excel functions to clean, transform, and analyze data:

`XLOOKUP` | `IF` | `COUNTIF` | `COUNTIFS` | `SUM` | `SUMIF` | `AVERAGE` | `TRIM` | `PROPER`

**3. Descriptive Statistical Analysis**

Performed statistical analysis on the Sales_Fact dataset, including:

- Total Sales
- Average Sales
- Median and Mode
- Maximum and Minimum Values
- Standard Deviation

**4. PivotTable Analysis**

Created multiple PivotTables to explore:

- Sales by Payment Type
- Sales by Store ID
- Average Quantity by Store ID
- Year-wise and Month-wise Sales

**5. Interactive Dashboard Development**

Developed an interactive Excel dashboard using Pivot Charts and Slicers, incorporating:

- Column Charts
- Pie Charts
- Line Charts
- Bar Charts

The dashboard enables dynamic filtering and exploration of sales performance across different dimensions.
